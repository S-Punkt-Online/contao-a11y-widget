# Contao A11y Widget

Ein einfaches Accessibility Widget als Frontend-Modul für Contao 5.

## Features

- Schriftgröße erhöhen/verringern
- Modus ohne Ablenkungen
- Links hervorheben
- einfache Sans-Serif-Schrift aktivieren
- Einstellungen werden im Browser gespeichert
- als Contao Frontend-Modul nutzbar
- Backend-Texte konfigurierbar

## Installation

composer require weba11y/contao-a11y-widget

## Verwendung

1. Im Contao Backend zu „Themes → Frontend-Module“ gehen.
2. Neues Modul vom Typ „Accessibility Widget“ erstellen.
3. Texte und Optionen konfigurieren.
4. Modul im Seitenlayout einbinden.

## Voraussetzungen

* Contao 5.3+
* PHP 8.1+
